# John's Electric Co.

A responsive one-page website for a Connecticut electrical service business covering Hartford, Waterford, Norwich, Waterbury and nearby areas.

## Features

- Responsive desktop and mobile layout
- Electrical service cards and coverage section
- Interactive service-request builder
- Native share and copy-to-clipboard support
- Accessible labels, keyboard navigation and reduced-motion support
- Automatic GitHub Pages deployment workflow

## Files

- index.html — page structure and content
- styles.css — responsive design and layout
- script.js — service-request builder interactions
- assets/ — optimized website imagery

## Run locally

Open index.html in a browser. No installation or build step is required.

## Publish with GitHub Pages

The included workflow publishes the site whenever the main branch is updated. In the repository settings, open **Pages** and choose **GitHub Actions** as the source if GitHub does not select it automatically.

## Before using it for the business

Add John's real phone number and email address. The current request builder keeps information on the visitor's device and lets them copy or share it; it does not send submissions to a server.
